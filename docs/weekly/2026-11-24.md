# 24 November 2026

## Tempestas 0.3.0: Thaumaturge aspects

Every Tempestas item and block now carries Thaumaturge aspects. Caught skies hold Aer, the salts hold Ignis or Gelum,
and the charms hold Praemunio. The aspects are datapack data that loads only when Thaumaturge is
installed, so Tempestas still runs fine without it, and packs can change any of them.

This update also fixes released ice melting in the Nether where vanilla ice does not, the Storm Charm's own bolt
recharging it, Weather Condenser output going over one stack, and skies with a bad biome id causing errors.

See the [Tempestas guide](../tempestas/index.md).

## Atramentum 0.6.0: Thaumaturge aspects

Every Atramentum item now carries Thaumaturge aspects. The Codex holds the most Cognitio, the Reading Glass reads as
Sensus and Vitreus, and inscribed vellum holds a little Praecantatio. Like Tempestas, the aspects are datapack data
that loads only when Thaumaturge is installed.

See the [Atramentum guide](../atramentum/index.md).
