# Thaumaturge addons

Thaumaturge brings Thaumcraft-style magic to 26.x. These are my addons for it. Each one has its own pages.

| Mod | What it does |
|---|---|
| [Arcana Varia](../arcanavaria/index.md) | Towers and labs to find, the Thurible, Lens and Lattice, and a set of weapons with a Warden to fight. |
| [Automagia](../automagy/index.md) | Magical workshop devices and an Inventarium storage network. |
| [Node Atlas](../other/node-atlas.md) | Log aura nodes and follow an arrow back to them. Client only. |
| [Classic Foci](../other/classic-foci.md) | Ready-made Portable Hole, Excavation and Equal Trade foci. |
| [Fieldframe Arcana](../fieldframe-arcana/index.md) | Connect essentia and vis to Fieldframe power and gear. It also sits under [Fieldframe](../fieldframe/index.md). |
| [Gadomancy](gadomancy.md) | Give golems more ways to work, automate item handling and essentia storage, and build around aura nodes. |
| [Magia Naturalis](magianaturalis.md) | Harvest with sickles, work with mutations and quicksilver, and keep supplies in magical storage. |
| [Planar Artifice](planarartifice.md) | Work glass into new building materials, use bismuth for transmutation, and move essentia through an alkimium workshop. |
| [Thaumaturgic Bases](thaumicbases.md) | Grow magical plants, make new wand parts and wearable gear, and extend the alchemical workshop. |
| [Thaumaturgic Tinkerer](tinkerer.md) | Add magical workshop gadgets, foci, controlled enchanting and transvector tools to Thaumaturge. |
| [Thaumaturgic Brewing](brewing.md) | Make potions in the crucible from essentia, then strengthen or extend them, or turn them into splash and lingering potions. |
| [Thaumaturgic Infusion](infusion.md) | Give an ordinary block an aspect effect on the infusion altar, then place it where you want that effect. |
