# Thaumaturge addons

Thaumaturge brings Thaumcraft-style magic to 26.x. These addons build on it. Each one has its own pages.

| Mod | What it does |
|---|---|
| [Arcana Varia](../arcanavaria/index.md) | Towers and labs to find, the Thurible, Lens and Lattice, and a set of weapons with a Warden to fight. |
| [Automagia](../automagy/index.md) | Magical workshop devices and an Inventarium storage network. |
| [Node Atlas](../other/node-atlas.md) | Log aura nodes and follow an arrow back to them. Client only. |
| [Classic Foci](../other/classic-foci.md) | Ready-made Portable Hole, Excavation and Equal Trade foci. |
| [Fieldframe Arcana](../fieldframe-arcana/index.md) | Connect essentia and vis to Fieldframe power and gear. It also sits under [Fieldframe](../fieldframe/index.md). |
| [Gadomancy Awakened](gadomancy.md) | Give golems more ways to work, automate item handling and essentia storage, and build around aura nodes. |
| [Arcana Naturae](magianaturalis.md) | Harvest with sickles, work with mutations and quicksilver, and keep supplies in magical storage. |
| [Primal Artifice](planarartifice.md) | Work glass into new building materials, use bismuth for transmutation, and move essentia through an alkimium workshop. |
| [Thaumaturgic Bases](thaumicbases.md) | Grow magical plants, make new wand parts and wearable gear, and extend the alchemical workshop. |
| [Thaumaturgic Tinkerer](tinkerer.md) | Add magical workshop gadgets, foci, controlled enchanting and transvector tools to Thaumaturge. |
| [Thaumaturgic Brewing](brewing.md) | Make potions in the crucible from essentia, then strengthen or extend them, or turn them into splash and lingering potions. |
| [Thaumaturgic Infusion](infusion.md) | The infusion altar gives an ordinary block an aspect effect, and the block keeps it wherever it is placed. |
| [Forsaken Magic](forsakenmagic.md) | Vice aspects and shards, dark enchantments, the Wrath Cage and morphic tools. |
| [Thaumaturgic Concilium](concilium.md) | 13 spell effects, crimson cultists, flux rifts and flesh alchemy. |
| [Arcane Accretions](arcaneaccretions.md) | Nine aspects, three new metals, big jars and void tools. |
| [Electro Magic Contraptions](electromagiccontraptions.md) | Electric tools and armour, essentia generators and solar panels on Forge Energy. |
| [Arcane Locomotion](arcanelocomotion.md) | Magic crowbars, an essentia-fired steam locomotive, essentia freight carts and eldritch rails for Railcraft Reborn. |
| [Crimson Revelations](crimsonrevelations.md) | Crimson cult gear, archers, new spell parts and enchantments, and a Thaumaturge villager's tower. |
| [Thaumic Augmentation](thaumicaugmentation.md) | Wards, impetus machines, rift studies, the Emptiness dimension, the Eldritch Spire and flight and weapon gear. |
| [Thaumic Boots](thaumicboots.md) | 26 pairs of boots for speed, jumping, stepping and fall control, each with its own power. |
| [Thaumic Exploration](thaumicexploration.md) | Wand cores and caps, rings, binding seals, urns and soul machines. |
| [Thaumic Wonders](thaumicwonders.md) | Alchemy tools, strange devices, the Primordial Accelerator and gear such as the Primal Destroyer and Flying Carpet. |
