# Thaumaturge addons

Thaumaturge brings Thaumcraft-style magic to 26.x. These are my addons for it. Each one has its own pages.

| Mod | What it does |
|---|---|
| [Arcana Varia](../arcanavaria/index.md) | Towers and labs to find, the Thurible, Lens and Lattice, and a set of weapons with a Warden to fight. |
| [Automagia](../automagy/index.md) | Magical workshop devices and an Inventarium storage network. |
| [Node Atlas](../other/node-atlas.md) | Log aura nodes and follow an arrow back to them. Client only. |
| [Classic Foci](../other/classic-foci.md) | Ready-made Portable Hole, Excavation and Equal Trade foci. |
| [Fieldframe Arcana](../fieldframe-arcana/index.md) | Connect essentia and vis to Fieldframe power and gear. It also sits under [Fieldframe](../fieldframe/index.md). |
