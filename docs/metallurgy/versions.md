# Versions

Metallurgy: Recast **1.4.8**

- Metallurgy loads on any stable NeoForge build for its game version. Before, 1.21.1 asked for one exact build and 26.1.2 for a recent one.

**1.4.7**

- With Spartan Weaponry Unofficial installed, every Metallurgy tool metal has Spartan Weaponry weapons on 1.21.1, as on 1.20.1. There are 23 weapon types for each of the 39 metals, with the original recipes, the metal's own tool stats and art drawn from Spartan's.
- With Better Combat installed, the Spartan melee weapons swing with the attack set of their Spartan type on 1.20.1 and 1.21.1. The attacks are datapack files, so packs can change them.
- The handbook recipe no longer logs an error on 1.20.1 when Patchouli is missing.

**1.4.6**

- The welcome message in chat when joining a world is gone, along with its config option.

**1.4.5**

- Armour effects run much faster on servers with many mobs. Mobs that wear no Metallurgy armour skip the armour check each tick, and each armour piece's metal is looked up once instead of every tick.
- Armour effects work the same as before.

**1.4.4**

- Replaced the remaining textures based on the original Metallurgy art: Haderoth and Lutetium armour, molten metals and particles.

**1.4.3**

- Molten metal bucket fills show under shaders. The Hephaestus compatibility code also handles the tier API in Hephaestus Tools 1.0.11.

**1.4.2**

- The jar now uses the Metallurgy: Recast name.

**1.4.1-port.27**

- First release as Metallurgy: Recast, with Metallurgy Chests merged in.
- An optional Patchouli handbook replaces the old wiki item.
- With Hephaestus Tools installed, the metals are tool materials with smeltery recipes, and 12 materials carry 14 of
  the original Tinkers' Construct traits.
- With Thaumaturge installed, each metal has a wand cap and rod.
- The Rubracium Gauntlet mines like an iron pickaxe and shovel and takes tool enchantments. One craft makes one
  gauntlet.
- JEI pages for every machine, detector programming and Tartarite absorption.
- Etherium Goggles no longer lag the inventory screen. The Electrum Magnet shows its new mode when switched.
  Detectors show what they are programmed to.
- Ore mining tiers can be changed in the config.
- Divine Grace only boosts direct melee hits from the weapon.
