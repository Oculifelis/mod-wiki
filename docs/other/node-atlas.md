# Node Atlas

Keep a log of the aura nodes you find, then follow an arrow back to the one you need. This is a client addon for [Thaumaturge](https://www.curseforge.com/projects/1628024), based on Thaumcraft Node Tracker by Dyonovan and GTNewHorizons.

**Requires** Thaumaturge 1.1.0 or newer. Install it on the client; it adds nothing to a dedicated server.

## Using the log

Right-click a node with a Thaumometer, or while wearing Goggles of Revealing, to save its position, type, modifier and aspects. Scanning it again updates the entry. The log is separate for each world or server.

Press **I** to open the list. Filter by primal aspect, sort by distance or an aspect, and mark a node. With revealing goggles equipped, the arrow points toward the marked node and shows its distance and whether it is above or below you. **Del** forgets an entry.

The config controls the arrow's position, size and plain red appearance. The port does not include the original Navigator or map waypoint layer.
