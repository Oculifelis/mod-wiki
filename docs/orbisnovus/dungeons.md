# Orbis Novus: Dungeons

![Orbis Novus: Dungeons](img/dungeons_logo.png){ width="128" align=right }

Dungeons, castles, villages and walled citadels, all placed in new chunks. The game assembles them from jigsaw
pieces, so no two are laid out the same. They're built in vanilla blocks, and they also use the blocks of any
building mods you have.

![A stone citadel](img/citadel_stone.png)

To find one, use `/locate structure`, for example `/locate structure orbisnovus_dungeons:crypt`. The other namespaces
are `orbisnovus_settlements:`, `orbisnovus_castles:` and `orbisnovus_citadels:` (for instance
`orbisnovus_citadels:citadel_stone`). The searches check biome and ground first, so they stay quick.

Structures generate only in chunks made after the mod is installed. Remove the mod and the ones already built stay as
blocks, but their chests come up empty.

with its own materials, lights, decay, biomes, mobs and loot. The pictures are cutaways: the ground round each dungeon

## Castles and citadels

**Castles** come in three styles: stone, sand and dark. Each is a keep inside a curtain wall, with turrets, a wall walk
and a gate.

| Picture | Castle | Style |
|---|---|---|
| ![Stone castle](img/shots/castle-castle_stone.jpg){ width="200" } | **Stone castle** | Stone |
| ![Sand castle](img/shots/castle-castle_sand.jpg){ width="200" } | **Sand castle** | Sand |
| ![Dark castle](img/shots/castle-castle_dark.jpg){ width="200" } | **Dark castle** | Dark |

**Citadels** are walled castle towns about 180 blocks across, in the same three styles, fitted to the ground they land
on. They're rare, roughly one per 1,500 blocks.

![A sand citadel](img/citadel_sand.jpg)

## The block library

![The same dungeons built from three different mods' blocks](img/dungeon_sets.jpg)

The structures ship in vanilla blocks. When building and decoration mods are installed, their blocks join a shared
library. Each structure picks from it once, to fit its theme and colours.

Each material (wall, floor, trim, pillar, ceiling and accents) draws one block, plus a second block for some of the
positions, so walls and floors mix two blocks. The world's seed drives the draw, so a dungeon is consistent inside and
comes out the same in the same world.

The library knows blocks from 33 mods. It only names their block ids; nothing from those mods is copied or bundled. A
block set is used only when its mod is loaded and every block it names exists, so the mod is safe with any mix of mods,
or none. Among them:

## Loot and spawners

| Thing | Table or tag | How it works |
|---|---|---|
| **Chests** | `orbisnovus:chests/<type>/<family>/<name>/<room>` down to `orbisnovus:chests/<room>` | Keep the kind of room they were built for: armoury, library, shrine, treasure, tomb, hoard and so on. The loot tables are layered; override one level in a datapack to change every chest below it. |
| **Barrels** | `orbisnovus:barrels/...` | Loot barrels. |
| **Spawners** | Entity type tags `orbisnovus:spawner/<type>/<family>/<name>`, then the family, then the type | An empty tag removes the spawner. Spawners appear only in dead or deserted places: [dungeons](#dungeons), ruins and the [mausoleum](#settlements-and-landmarks). Lived-in castles, citadels, villages and temples have none. |
| **Structure tags** | `#orbisnovus:type/<type>` and `#orbisnovus:family/<type>/<family>` | |

## Config

`config/orbisnovus_dungeons-common.toml`:

| Key | Default | What it does |
|---|---|---|
| `mod_sets` | `true` | Use installed mods' blocks from the library. `false` keeps everything vanilla. |
| `disabled_sets` | `[]` | Mod ids whose blocks are never used, such as `["rechiseled"]`, or `"vanilla"`. A dungeon with every set turned off doesn't generate. |
| `village_houses` | `"add"` | Orbis Novus houses in vanilla villages: `"add"`, `"replace"` or `"off"`. |
| `village_weight` | `1` | Multiplies the added houses' pool weights (1 to 20). |
| `castle_block_swaps` | `true` | Build castles from a loaded building mod's stone and wood. |
| `citadels` | `true` | Citadels in the world. |

Everything else is datapack JSON under `data/orbisnovus_dungeons/`, `orbisnovus_settlements/`, `orbisnovus_castles/`,
`orbisnovus_citadels/` and `orbisnovus/` (loot and tags). A datapack can override or add to any of the structures,
structure sets (spacing), template pools, processor lists and biome tags.

## Compatibility

| Mod | How it works |
|---|---|
| [Lootr](https://www.curseforge.com/projects/361276) | Works. Every chest and barrel holds only a loot table, with nothing pre-filled, so Lootr turns them into per-player containers just as it does vanilla's. |
| [Orbis Novus: Terrain](terrain.md) | Dungeons and settlements generate in its world types. |
| Other world generation mods (biome mods, terrain mods) | Structures follow biome tags, so they place in modded biomes that carry the usual `#minecraft:` and `#c:` tags. |
| Structure mods that change vanilla villages | May change how often the added houses appear. |

**Multiplayer:** the structures are built on the server; install the mod on both sides.

| Wonder | Command |
|---|---|
| Clockwork Labyrinth | <code>/locate structure orbisnovus_wonders:clockwork_labyrinth</code> |
| Inverted Spire | <code>/locate structure orbisnovus_wonders:inverted_spire</code> |
| Living Barrow | <code>/locate structure orbisnovus_wonders:living_barrow</code> |
| Bottled Ship | <code>/locate structure orbisnovus_wonders:bottled_ship</code> |
| Hall of Echoes | <code>/locate structure orbisnovus_wonders:hall_of_echoes</code> |
| Giant’s Desk | <code>/locate structure orbisnovus_wonders:giants_desk</code> |
| Upside-down Village | <code>/locate structure orbisnovus_wonders:upside_down_village</code> |

The Clockwork Labyrinth’s gates change on a redstone clock started with a button. Giant’s Desk is disabled by default; the giants_desk config option enables it.

The wonders have their own loot, spawners and structure locations. Six deep dungeons stack different kinds into separate levels. Buried dungeons get marked surface entrances in three designs, chosen by the world seed; gatehouses and shrines also get three designs.

Trap corridors, ambush rooms and guard rooms add more encounters, with suitable modded monsters used when installed. Structure details include connected panes, bars, fences, walls and stairs, complete doors and beds, supported wall fixtures and foundations reaching solid ground. Citadel spacing is 72 with separation 30.
