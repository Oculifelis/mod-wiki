# Oculifelis's mod wiki

One site for all of Oculifelis's Minecraft mods: Fundamentum and Ostentum so far. Built with MkDocs Material.

    pip install -r requirements.txt
    mkdocs serve          # live preview at http://127.0.0.1:8000
    mkdocs build --strict # the site in site/

To add a mod, see `docs/adding-a-mod.md`.

Publishing: turn on GitHub Pages with "GitHub Actions" as the source, then run the "Publish wiki" workflow.

By Oculifelis.
